# Changelog

## 1.1.1 (2026-11-24)

- 日志格式强制带方法名，禁止退化成只写业务描述；来源：`insert` 与 `insert2` 业务描述相同导致日志无法区分。

## 1.1.0 (2026-11-18)

- 红线移至 `coding-habit-template.md` 顶部；来源：红线可能被跳过。
- 单行上限定为 160 字符；来源：团队规范。
- 新增"简洁表达优先"和链式/Stream 排版规则；来源：正向授权缺失，AI 倾向啰嗦。
- 新增动词/名词统一约束；来源：同语义混用 get/fetch/query/load。
- 新增"意图与正确性 → 清晰 → 性能"的动手顺序；来源：缺少动手优先级。
- 新增方法 80 行、类 1000 行体量软红线；来源：只有"类大不是拆分理由"，缺可执行阈值。
- 新增测试最小模板；来源：测试章节无模板。
- 新增存量代码修改示例；来源：存量修改缺少保留/规范化示例。
- 新增并发、事务、日志片段；来源：纯文字清单缺少正反例。
- 新增审查独立路由、拆类信号、权限最小范围；来源：审查入口混淆、判断标准缺失。
- 新增新项目默认集；来源：无项目约定时缺少最小默认。
- 新增"开工前"探测与五口径（时间、计数、状态、幂等、分页）；来源：跨文件口径不一致导致返工。
- 按需加载改为按代码特征触发；来源：按话题判断会漏读并发与持久化规则。
- 补 SQL 存放与 XML 绑定校验、游标分页不查总数；来源：注解 SQL 与分页实现偏离项目约定。
- 补事务/编排方法最小日志集；来源：只在末尾打一条"完成"充当节点日志。
- 补交付前自检、无预留与口径一致性检查；来源：预留枚举/错误码与口径漂移。
